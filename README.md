# task-manager-flutter-firebase (Assignment no. 4)
Task Manager Mobile Application using Flutter and Firebase.
Task Manager App (Flutter + Firebase)

🛠️ Technologies Used
- Framework: Flutter
- Language: Dart
- Backend: Firebase (Cloud Firestore)
- Platform: Android / iOS
- Version Control: Git & GitHub


-> 📱 Application Features
 1. Home Screen
- Displays list of tasks from Firebase
- Shows task title, description, and status

2. Add Task
- Add new task with title and description
- Optional due date support
- Save task to Firebase

3. Update Task
- Edit task title and description
- Mark task as completed
- Update data in Firebase

4. Delete Task
- Remove task permanently from Firebase
